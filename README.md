Calculatrice Python
# Description

Ce projet est une calculatrice développée en Python avec Tkinter.

Elle permet de réaliser les opérations suivantes :

Addition

Soustraction

Multiplication

Division

Un petit jeu Snake est également intégré à la calculatrice.

# Fonctionnalités
Calculatrice

Entrer des nombres

Additionner deux nombres

Soustraire deux nombres

Multiplier deux nombres

Diviser deux nombres

Effacer l'écran

# Snake

Le jeu Snake est accessible avec le bouton prévu dans la calculatrice.

Le joueur peut déplacer le serpent avec les touches directionnelles du clavier.

Le jeu se termine lorsque le serpent touche un mur ou son propre corps.
